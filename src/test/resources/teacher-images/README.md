# Entradas originais da professora

Estas 15 imagens foram fornecidas pelo usuário no ZIP `a0d11a17-f088-4f30-b914-b2df05b6e2ec.zip`. Os arquivos foram preservados byte a byte, com os nomes e os formatos originais.

`manifest.json` registra os hashes SHA-256 e as dimensões das imagens e o hash do arquivo ZIP de origem. Não regenerar estas entradas com o gerador de exemplos sintéticos.

Os horários esperados informados pelo usuário são, respectivamente, 07:31, 03:00 ou 02:59, e 10:15 (corrigido e confirmado pelo usuário). O [relatório de validação](../../../../docs/teacher-images.md) descreve os demais gabaritos, os resultados observados e o comando para executar `TeacherImagesTest`.
